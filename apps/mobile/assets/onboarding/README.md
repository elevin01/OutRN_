# Onboarding interest photography

These eight bundled photographs come from the approved October 4 onboarding storyboard's Unsplash
imagery. They illustrate interests, not particular venues, availability, or recommendations. Keep them
within the interest picker and its background; never use them as photographs of an API result.

Bundling the small images keeps the first introduction usable without eight external image requests.
Their presence is checked during export. The separate `assets/photos` demo venue content retains
its existing production exclusion.
