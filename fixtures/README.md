# Fixtures

`osm/*-synthetic.json` are **invented** Overpass-shaped responses generated by `osm/generate.mjs`.
No venue in them exists. They exist so the whole pipeline (connector → raw store → normalize →
resolve → materialize → engine) runs offline and in tests with identical code paths to a live fetch.

They deliberately include the identity-resolution traps the plan calls out: the same café mapped
as a node and a building way, a two-branch chain sharing a website and phone, a museum with a café
inside it, a permanently closed bar, six-year-old hours, a viewpoint with no hours, and an overnight bar.

To capture a **real** response from a machine with network access:

    pnpm outrn ingest osm --area les --save fixtures/live/les.json

`fixtures/live/` is gitignored; real OSM data is ODbL and must be attributed when redistributed.

`nws/les-hourly-sample.json` is an **invented** National Weather Service hourly forecast in the shape
api.weather.gov returns (Saturday 3 Oct 2026, noon to 8pm in New York: rain from 2pm), for the
weather tests. Replay a real one with `outrn weather refresh --area les --from-file <path>`.
